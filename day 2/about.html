About Quicknotes

QuickNotes is a simple note-taking application built to ease note-taking for students and professionals

QuickNotes is your digital diary

How to use QuickNotes

  • Open your browser and navigate to the QuickNotes website
  • Type a note in the input field
  • Click the "Add note" button
  • The note will be added to the list of notes

Keyboard Shortcuts

Keyboard Shortcut Action
N Add a new note
D Delete a note
