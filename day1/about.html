About Quicknotes

QuickNotes is a simple note-taking application built to ease note-taking for students and professionals

QuickNotes is your digital diary

How to use QuickNotes

  1. Open your browser and navigate to the QuickNotes website
  2. Type a note in the input field
  3. Click the "Add note" button
  4. The note will be added to the list of notes

Keyboard Shortcuts

Keyboard Shortcut Action
N Add a new note
D Delete a note
